# RailroaderRV server Lua

- `RV_Server.lua` composes the server event handlers and generation transaction modules.
- `RV_RailroaderServer*.lua` handles server-authoritative Railroader entry, exit, mapping, and transition validation.
- `RV_BoundaryServer*.lua` implements bitmap-scoped boundary tracking and transition leases. `RV_Server_TemplateRepair.lua` samples validated RV occupants every 10 server ticks, deduplicates their 3x3 neighborhoods by RV generation, and checks at most one XY column per server tick across the managed Z layers. Work pauses without a current occupant; the z0 cab interior is exempt, while the roof and other captured template objects remain protected.
- `RV_Server_*.lua`, `RV_ServerSchema.lua`, and `RV_ServerWorld.lua` provide generation, persistence validation, and world operations; `RV_Utility*.lua` and `RV_RoofRepair.lua` provide utility and repair services.
- `RV_Server_RoomOwnership.lua` repairs invalid RoomDef references with synchronous transaction scans, an authoritative current-square check for online players each tick, a 3x3 neighborhood probe every 120 ticks, and merged object-event scans with bounded delayed rechecks. Full scans require every base structure square and every captured roof-object host to be loaded; incomplete scans remain unconfirmed.
- Generation waits at the staging point while its required base footprint and shell squares load. Captured upper objects are created at their logged coordinates; the first required full RoomDef scan runs after the captured-object pass and before final relocation. If generation fails before that pass completes, rollback scans the old structure plus only upper squares already materialized in the transaction cell. Once the pass completes, rollback requires all captured roof-object hosts; missing required squares keep rollback failed.
- Keep world changes authoritative on the server, accept client intent only, and reject persisted data that does not match the current declared schema.
- TEMPORARY `[RailroaderRVTest][PerfTrace]` summaries in `RV_Server_RoomOwnership.lua` report RoomDef guard probes and scans in aligned 10-second windows. The boundary proximity queue and utility paths do not emit PerfTrace summaries.
