# RailroaderRV server Lua

- `Core/` owns the server facade, command/event routing, and the Railroader adapter entry point. `Construction/` owns generation validation, staging, sparse cleanup, captured-object build, ACK handling, and rollback.
- `Common/` owns server world, the single Lua-declared schema version, ModData persistence, utility, and shared domain helpers. The schema version is checked once at mod startup; a mismatch only warns and does not block operation. `RVMapping/` owns current RV records and Railroader entry/exit. `BoundaryGuard/` owns the authoritative AABB guard and transition leases.
- `RoofRefresh/` owns roof/room refresh coordination and room-ownership checks. `DemolitionProtection/` owns shell-wall attribution. `TemplateRecovery/` owns current-template repair. `Power/` and `Water/` contain their respective server services.
- Generation waits at staging for the target IsoCell and validates destination coordinates; it does not require all 10,000 base squares or upper layers to exist first. Cleanup walks the managed bounds but clears only squares already present in the cell, skipping missing squares. Before mutation, Construction fails closed if the target contains any existing object or an old generation lacks a complete undo snapshot. Build creates objects only at current template-object hosts and materializes missing host squares on demand; it does not create empty base-plane squares. The first required full RoomDef scan runs after the captured-object pass and before final relocation. If generation fails before that pass completes, rollback scans the old structure plus only upper squares already materialized in the transaction cell. Once the pass completes, rollback requires all captured roof-object hosts; missing required squares keep rollback failed.
- Keep world changes authoritative on the server and accept client intent only. Runtime code assumes persisted data and module interfaces match their current definitions; do not add repeated schema checks or inter-module interface guards, compatibility, or migration paths. Let errors surface as normal game exceptions for later diagnosis.
- The flat server Lua files retained beside these module folders are forwarding entry points for moved code. Implementation ownership stays with the file under its module directory.
