# RailroaderRV test server scripts

- `run_test.py` stages the local `RailroaderRV` and `BuildingCraft` mods, starts the server using its existing profile, and launches the visible server console plus the regular game client.
- Maintain server mod settings in the INI already present at the selected server cache's `Server/test.ini`. The default Z: INI uses `Mods=BuildingCraft;Railroader;RailroaderRV;B42Trans_CN` and `WorkshopItems=3556544454;3774360904`. The launcher does not create, rewrite, or copy the server INI or `test_SandboxVars.lua`. The workspace copy under `testserver/runtime/server` is a local reference or optional custom cache, not the default server profile or a fallback source.
- The default server and client cache roots are `Z:\RailroaderRVCache\server` and `Z:\RailroaderRVCache\client`. Each process receives its cache through `-cachedir`; saves, logs, settings, and staged mods therefore stay together on the RAM disk.
- The launcher initializes only the client RAM disk cache. On first use, it copies `testserver/runtime/client` only when the Z: destination does not exist. A layout marker under `testserver/runtime/` records Z: cache locations; an older marker can retain a server entry, but the launcher no longer uses it to copy or select the server cache. Ambiguous client caches or a missing previously registered Z: client cache stop startup instead of merging or recreating from a potentially stale copy.
- The Z: caches and their saves/logs are not copied back or automatically deleted. They survive launcher runs while the RAM disk contents survive; a volatile RAM disk reset can lose them. Users manage Z: capacity and preserve any needed data before clearing it.
- The persistent server cache retains its saves, player database and admin permissions between runs; the launcher does not automatically reset that data.
- The Windows launcher selects the UTF-8 console code page and Java file encoding for startup output.
- Passing `--client-cache` or `--server-cache` explicitly overrides that process's default Z: path. Maintain any server INI and SandboxVars files in the selected server cache. The one-click runtime test remains `python testserver/run_test.py` from the project root; do not start a separate server or client for runtime verification.
